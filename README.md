# E-Commerce Shopping System

## 📌 Project Overview

The **E-Commerce Shopping System** is a console-based application developed using **Core Java**. The project simulates the basic operations of an online shopping platform, including customer management, product management, cart management, order processing, payments, shipments, and product reviews.

The application provides separate **Customer and Admin modules** and follows a structured service-based approach.

---

## 🎯 Project Objective

The main objective of this project is to develop a simple e-commerce application using **Core Java and Object-Oriented Programming concepts**.

The project helps demonstrate how different e-commerce components such as customers, products, categories, suppliers, carts, orders, payments, shipments, and reviews can be connected and managed within a single application.

---

## 📦 Project Modules

The project is divided into the following modules:

### Main Module
- `Ecom.java` – Main class that controls the application flow and menus.

### Modules Package
- **User** – Common user information
- **Admin** – Admin-related operations
- **Customer** – Customer information and operations
- **Category** – Product category details
- **Supplier** – Supplier information
- **Product** – Product details, price, and stock
- **Cart** – Shopping cart management
- **CartItem** – Individual cart products
- **Orders** – Order information
- **OrderItems** – Products included in an order
- **Payment** – Payment details
- **Shipment** – Shipment and delivery details
- **Review** – Product reviews and ratings

### Services Package
- **UserServices** – Customer and Admin operations
- **ProductServices** – Product, category, and supplier operations
- **CartServices** – Cart operations
- **OrderServices** – Order, payment, shipment, and review operations
- **ReportServices** – Generates business reports
